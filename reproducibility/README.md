# Reproducibility Metadata

This directory stores generated environment metadata that is bundled in the replication package.

- python-env/python-version.txt: exact Python interpreter version from .venv
- python-env/requirements-lock.txt: exact pip lock snapshot (`pip freeze --all`)
- python-env/pip-list.json: installed package inventory in JSON format
- python-env/kernelspecs.json: available Jupyter kernels at packaging time
- python-env/platform.txt: host platform information
